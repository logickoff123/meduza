## Установка и запуск

Для начала необходимо настроить проект и запустить приложение. Следуйте шагам ниже:

### 1. Создание виртуального окружения и установка зависимостей

Создайте виртуальное окружение и установите все необходимые библиотеки из файла `requirements.txt`. Для этого выполните следующую команду:

```bash
pip install -r requirements.txt

```



2.Указание пути к весам модели в app.py

В файле app.py нужно указать путь к весам модели. Для этого выполните следующие шаги:

Перейдите в директорию cvtt_ft/weights/ и найдите файл best.pt.

Щелкните правой кнопкой мыши на файл best.pt и выберите Copy path (Копировать путь).

Откройте файл app.py и найдите строку, где инициализируется модель, и замените её на:

model = YOLO("вставьте_скопированный_путь_к_best.pt")


3. Запуск скрипта

После того как путь к весам будет указан, запустите приложение с помощью команды:

```bash
streamlit run app.py

```

После этого приложение откроется в вашем браузере на локальном хосте, и вы сможете взаимодействовать с ним.
