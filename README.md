### Что нужно сдлеать 

Для начала создать виртуальное окружение и установить из файла 
requirements.txt все библиотеки, сделать это с помощью команды 


pip install -r requirements.txt


После чего зайти в app.py В данном файле надо указать путь к весам. Для этого зайди 
в cvtt_ft -> weights-> best.pt 

Правой кнопкой мыши нажми на best.pt и выбери Copy path поле чего вставь его в app.py
а именно в эту строку 

model = YOLO("скопированный путь")

Запустить скрипт можно с помощью команды 

streamlit run app.py


После чего вас автоматом перекинет на локал хост где вы сможете тыкаться как вам угодно.
